Workflow Guide

A safer cleanup process for client sites and production media libraries

Short version

Analyze first, preview second, Trash third, verify fourth, and regenerate only when there is a real missing-size need.

When to use analysis

Use analysis before any big cleanup. It helps you understand which image sizes are consuming space and whether orphan or unused media exists.

When to use preview

Use preview any time you are about to remove files. This is especially important on sites with custom themes, page builders, or imported legacy media.

When Trash is safer than deletion

Trash is the best default when you work on a live site, a client site, or a library with mixed historical content. It lets you reverse the change without pulling from backup immediately.

When to regenerate

Regenerate only after confirming a size is needed. Rebuilding missing derivatives is useful after restoring a workflow, enabling a size again, or migrating a theme that expects specific dimensions.

Suggested operating checklist

  1. Run analysis and review size analytics.
  2. Limit your first preview to one size or one folder.
  3. Move matching files to Trash.
  4. Check a few representative posts or products.
  5. Restore if anything unexpected appears.
  6. Regenerate missing sizes for approved dimensions.
