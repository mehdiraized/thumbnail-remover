WordPress thumbnail remover plugin

Remove WordPress thumbnails safely without breaking your media workflow.

Thumbnail Remover and Size Manager is a WordPress plugin for removing thumbnails, previewing image cleanup, restoring removed files, detecting orphan thumbnails, reviewing unused media signals, and regenerating missing image sizes.

What this WordPress plugin does

This plugin is designed for site owners, developers, support teams, and agencies who need a safer way to manage WordPress thumbnails. Instead of deleting image sizes blindly, you can analyze your media library, preview the exact impact, move thumbnails to plugin Trash, restore them if needed, and regenerate missing sizes after cleanup.

Analyze WordPress thumbnails

See storage usage, missing sizes, orphan thumbnails, and signals for media that may no longer be used.

Preview before delete

Check how many thumbnails match your filters and how much disk space can be recovered before cleanup starts.

Restore after cleanup

Use plugin Trash batches to restore removed thumbnails when a rollback is needed.

Regenerate missing thumbnails

Rebuild only the image sizes that are missing instead of regenerating the full media library every time.

Frequently searched questions

How do I remove thumbnails in WordPress safely?

Use a workflow that lets you analyze, preview, trash, restore, and regenerate thumbnails instead of deleting files immediately.

Can I regenerate only missing thumbnails?

Yes. This plugin focuses on regenerating missing image sizes so you do not always need a full library-wide regenerate.

Can I restore thumbnails after cleanup?

Yes. Cleanup runs are stored in plugin Trash batches so you can restore them later when needed.
