Why this plugin exists

Safer cleanup for real WordPress media libraries

Many thumbnail tools jump straight to regeneration or deletion. This plugin adds the missing safety layer: preview first, move files to Trash, restore if needed, and then rebuild only the missing sizes.

Library analysis

Scan attachments, see thumbnail storage, spot missing sizes, review orphan files, and surface probably unused media.

Preview before cleanup

Check matching files, storage impact, and affected sizes before moving anything out of uploads.

Trash and restore

Removed thumbnails are batched into plugin Trash so you can reverse a cleanup if a site owner changes direction.

Regenerate only what is missing

Rebuild missing derivatives without forcing a full library-wide regenerate when you only need targeted recovery.

Product walkthrough

What the workflow looks like in the plugin UI

1. Analyze your library

See counts, storage, orphan thumbnails, missing sizes, and unused media indicators before cleanup.

2. Preview the cleanup

Estimate exactly how many files match and how much disk space will be recovered.

3. Keep a restore path

Every cleanup run creates a batch in plugin Trash so you can restore later if needed.

4. Regenerate missing sizes

Rebuild only the missing derivatives after you re-enable or keep selected image sizes.
