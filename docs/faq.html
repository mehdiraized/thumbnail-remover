FAQ

Frequently asked questions

Does the plugin permanently delete thumbnails?

Not during cleanup. The main workflow moves matching thumbnails to plugin Trash first so you can restore them later. Use Delete Permanently for one batch or Empty Trash for all batches when you are ready to remove files from disk.

How do I empty the plugin Trash?

Use Empty Trash in the Trash and Restore table to remove every batch, or use Delete Permanently for a single batch. This deletes the stored trash files and any backup stored with those batches, and it cannot be undone.

What are orphan thumbnails?

Orphan thumbnails are image files that still exist on disk but are no longer tracked inside attachment metadata.

What does probably unused media mean?

The plugin checks for signals like featured image usage, post content references, and common builder or meta content. It is a review signal, not an automatic delete decision.

Can I regenerate only missing sizes?

Yes. That is one of the core workflows in version 2. You can regenerate only the sizes that are missing.

Where do I install the plugin?

You can install it from WordPress.org.
