Getting Started

Install, analyze, preview, and clean up safely

This guide walks through the safest first run for a production WordPress site.

1. Install the plugin

  1. Open the WordPress.org plugin page.
  2. Install and activate the plugin on your WordPress site.
  3. Go to Tools > Thumbnail Manager.

2. Run a full analysis

Start with analysis before any cleanup. This gives you visibility into thumbnail storage, missing sizes, orphan files, and probably unused media.

3. Preview cleanup

Select the size or upload folder you want to target, then use Preview Cleanup to estimate impact before moving files.

4. Move matching files to Trash

When you are confident in the preview, move the matching files to plugin Trash. This gives you a restore path instead of permanent deletion.

5. Regenerate missing sizes

If you re-enable or keep a size, use batch regeneration to rebuild only what is missing.

Recommended first workflow

  1. Create a backup if the site is production-critical.
  2. Run analysis and review the data.
  3. Preview a narrow selection first.
  4. Move matching files to Trash.
  5. Verify the front end if needed.
  6. Restore a batch if something needs to be reversed.
  7. Regenerate missing sizes only where needed.
